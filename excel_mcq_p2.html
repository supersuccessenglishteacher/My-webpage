📊 MS Excel Challenge (Part 2)

Super Success Computer Education Center

অ্যাডভান্সড
১১. এক্সেলে গড় (Average) বের করার সঠিক ফর্মুলা কোনটি?
(A) =AVG()   (B) =AVERAGE()   (C) =MEAN()   (D) =SUM_DIV()
সঠিক উত্তর: (B) =AVERAGE()
১২. কোনো সেলের ভেতর আজকের তারিখ (Today's Date) আনার শর্টকাট কোনটি?
(A) Ctrl + ; (Semicolon)   (B) Ctrl + Shift + ;   (C) Alt + D   (D) Ctrl + T
সঠিক উত্তর: (A) Ctrl + ; (Semicolon)
১৩. এক্সেল শিটে ডাটাকে গ্রাফিক্যালি দেখানোর জন্য কোনটি ব্যবহার করা হয়?
(A) Table   (B) Charts   (C) Pivot   (D) ClipArt
সঠিক উত্তর: (B) Charts
১৪. এক্সেলে কতগুলো সেলে সংখ্যা আছে তা গুনার (Count) জন্য কোন ফর্মুলা ব্যবহৃত হয়?
(A) =TOTAL()   (B) =NUMBER()   (C) =COUNT()   (D) =SUM()
সঠিক উত্তর: (C) =COUNT()
১৫. এক্সেল ফাইলে পাসওয়ার্ড দিয়ে সেভ করার অপশন কোথায় পাওয়া যায়?
(A) Review Tab   (B) Home Tab   (C) Data Tab   (D) View Tab
সঠিক উত্তর: (A) Review Tab (Protect Sheet)
১৬. এক্সেলে কলাম (Column) এবং রো (Row) কে একসাথে লক করে দেওয়ার পদ্ধতিকে কী বলে?
(A) Lock Cells   (B) Freeze Panes   (C) Hold View   (D) Split Window
সঠিক উত্তর: (B) Freeze Panes
১৭. অনেকগুলো ডাটার মধ্য থেকে নির্দিষ্ট ডাটা খুঁজে বের করার টুল কোনটি?
(A) Sort   (B) Filter   (C) Wrap Text   (D) Alignment
সঠিক উত্তর: (B) Filter
১৮. এক্সেল শিটে একদম শেষ সেলে যাওয়ার শর্টকাট কী কোনটি?
(A) Ctrl + End   (B) Ctrl + Home   (C) Page Down   (D) Alt + End
সঠিক উত্তর: (A) Ctrl + End
১৯. এক্সেলে কোনো সেলের লেখা যদি বড় হয়, তবে তাকে এক জায়গায় দেখানোর জন্য কোনটি ব্যবহৃত হয়?
(A) Merge   (B) Wrap Text   (C) Shrink   (D) Justify
সঠিক উত্তর: (B) Wrap Text
২০. কিবোর্ডের কোন বোতাম চাপলে অটো-সাম (AutoSum) ফর্মুলা কাজ করে?
(A) Alt + =   (B) Ctrl + =   (C) Shift + =   (D) Alt + S
সঠিক উত্তর: (A) Alt + =
