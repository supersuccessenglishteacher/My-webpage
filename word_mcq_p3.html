📝 MS Word Challenge (Part 3)

Super Success Computer Education Center

প্রফেশনাল লেভেল
২১. ডকুমেন্টের ব্যাকগ্রাউন্ডে ঝাপসা লেখা বা ছবি দেওয়াকে কী বলা হয়?
(A) Page Color   (B) Watermark   (C) Page Border   (D) Ghost Text
সঠিক উত্তর: (B) Watermark
২২. পেজটি লম্বালম্বি (Portrait) নাকি আড়াআড়ি (Landscape) হবে—তা কোন অপশন থেকে ঠিক করা হয়?
(A) Size   (B) Margin   (C) Orientation   (D) Columns
সঠিক উত্তর: (C) Orientation
২৩. কিবোর্ডের মাধ্যমে ফন্ট সাইজ (Font Size) বড় করার শর্টকাট কী কোনটি?
(A) Ctrl + [   (B) Ctrl + ]   (C) Ctrl + F   (D) Ctrl + P
সঠিক উত্তর: (B) Ctrl + ]
২৪. MS Word-এ 'Subscript' (যেমন: H₂O) করার শর্টকাট কী কোনটি?
(A) Ctrl + Equals(=)   (B) Ctrl + Shift + Plus(+)   (C) Alt + B   (D) Ctrl + D
সঠিক উত্তর: (A) Ctrl + Equals(=)
২৫. একটি বড় লেখাকে দুই বা ততোধিক কলামে (যেমন সংবাদপত্রে থাকে) ভাগ করার অপশন কোনটি?
(A) Split   (B) Columns   (C) Table   (D) Break
সঠিক উত্তর: (B) Columns
২৬. পেজের চারদিকে সুন্দর বর্ডার দেওয়ার জন্য কোন ট্যাব ব্যবহার করা হয়?
(A) Home   (B) Design / Layout   (C) Review   (D) References
সঠিক উত্তর: (B) Design / Layout (উইন্ডোজ ভার্সন ভেদে আলাদা হতে পারে)
২৭. সিলেক্ট করা লেখাকে ছোট হাতের থেকে বড় হাতের (Case Change) করার শর্টকাট কী?
(A) Shift + F3   (B) Alt + F3   (C) Ctrl + F3   (D) F3
সঠিক উত্তর: (A) Shift + F3
২৮. ডকুমেন্টে কোনো শেপ (Shape) বা ছবি ইনসার্ট করার পর কোন নতুন ট্যাবটি দেখা যায়?
(A) Format / Picture Format   (B) Design   (C) Layout   (D) Edit
সঠিক উত্তর: (A) Format / Picture Format
২৯. প্যারাগ্রাফের শুরুতে একটি বড় অক্ষর (যেমন ম্যাগাজিনে থাকে) তৈরি করাকে কী বলে?
(A) WordArt   (B) Drop Cap   (C) Big Font   (D) Text Wrap
সঠিক উত্তর: (B) Drop Cap
৩০. ডকুমেন্ট সরাসরি সেভ না করে অন্য কোনো নামে সেভ করার জন্য কোনটি ব্যবহৃত হয়?
(A) Save   (B) Open   (C) Save As   (D) Export
সঠিক উত্তর: (C) Save As
