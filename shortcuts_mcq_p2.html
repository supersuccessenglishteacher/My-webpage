ব্রাউজার শর্টকাট
১১. ইন্টারনেটে ব্রাউজ করার সময় নতুন একটি 'ট্যাব' (New Tab) খোলার শর্টকাট কোনটি?
(A) Ctrl + N   (B) Ctrl + T   (C) Ctrl + Tab   (D) Ctrl + W
সঠিক উত্তর: (B) Ctrl + T
১২. ভুল করে কোনো ট্যাব বন্ধ হয়ে গেলে সেটি আবার ফিরিয়ে আনার (Reopen Closed Tab) কমান্ড কোনটি?
(A) Ctrl + Shift + T   (B) Ctrl + Z   (C) Ctrl + R   (D) Ctrl + T
সঠিক উত্তর: (A) Ctrl + Shift + T
১৩. টাইপ করা টেক্সটকে 'ইটালিক' (Italic) বা বাঁকা করার কমান্ড কোনটি?
(A) Ctrl + B   (B) Ctrl + I   (C) Ctrl + U   (D) Ctrl + L
সঠিক উত্তর: (B) Ctrl + I
১৪. কোনো টেক্সটের নিচে 'আন্ডারলাইন' (Underline) দেওয়ার জন্য কোনটি চাপতে হয়?
(A) Ctrl + L   (B) Ctrl + U   (C) Ctrl + N   (D) Ctrl + Alt + U
সঠিক উত্তর: (B) Ctrl + U
১৫. কম্পিউটারের 'মাই কম্পিউটার' বা 'ফাইল এক্সপ্লোরার' সরাসরি খোলার শর্টকাট কোনটি?
(A) Win + E   (B) Win + F   (C) Win + D   (D) Win + L
সঠিক উত্তর: (A) Win + E (E তে Explorer)
১৬. চালু থাকা সব উইন্ডো একবারে মিনিমাইজ করে 'ডেস্কটপ' (Desktop) দেখার কমান্ড কোনটি?
(A) Win + M   (B) Win + D   (C) Ctrl + D   (D) Both A and B
সঠিক উত্তর: (D) Both A and B (সাধারণত Win + D বেশি ব্যবহৃত হয়)
১৭. কোনো একটি ফাইল বা ফোল্ডার 'রিনেম' (Rename) করার শর্টকাট কি কোনটি?
(A) F1   (B) F2   (C) F5   (D) F12
সঠিক উত্তর: (B) F2
১৮. কোনো পেজ বা উইন্ডোকে 'রিফ্রেশ' (Refresh) করার জন্য কীবোর্ডের কোন বাটনটি চাপতে হয়?
(A) F2   (B) F5   (C) F11   (D) Alt + R
সঠিক উত্তর: (B) F5
১৯. বর্তমানে ব্যবহৃত উইন্ডোটিকে ঝটপট 'লক' (Lock PC) করার কমান্ড কোনটি?
(A) Win + L   (B) Ctrl + L   (C) Win + P   (D) Alt + L
সঠিক উত্তর: (A) Win + L
২০. কোনো ফাইলকে রিসাইকেল বিনে না পাঠিয়ে চিরস্থায়ীভাবে ডিলিট (Permanent Delete) করার কমান্ড কোনটি?
(A) Delete   (B) Ctrl + Delete   (C) Shift + Delete   (D) Alt + Delete
সঠিক উত্তর: (C) Shift + Delete
