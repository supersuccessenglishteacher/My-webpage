১. MS Word-এ নতুন একটি ডকুমেন্ট খোলার শর্টকাট কী কোনটি?
(A) Ctrl + O   (B) Ctrl + N   (C) Ctrl + S   (D) Ctrl + M
সঠিক উত্তর: (B) Ctrl + N
২. কোনো লেখাকে পেজের একদম মাঝখানে (Center) আনার শর্টকাট কী?
(A) Ctrl + C   (B) Ctrl + L   (C) Ctrl + E   (D) Ctrl + R
সঠিক উত্তর: (C) Ctrl + E
৩. MS Word-এ বানান ভুল হলে শব্দের নিচে কোন রঙের আঁকাবাঁকা দাগ দেখা যায়?
(A) নীল   (B) সবুজ   (C) লাল   (D) কালো
সঠিক উত্তর: (C) লাল (Red)
৪. সিলেক্ট করা লেখাকে মোটা (Bold) করার জন্য কোনটি ব্যবহার করা হয়?
(A) Ctrl + B   (B) Ctrl + I   (C) Ctrl + U   (D) Ctrl + P
সঠিক উত্তর: (A) Ctrl + B
৫. ডকুমেন্টের কোনো শব্দ খোঁজার (Find) জন্য কোন শর্টকাট ব্যবহৃত হয়?
(A) Ctrl + H   (B) Ctrl + F   (C) Ctrl + G   (D) Ctrl + K
সঠিক উত্তর: (B) Ctrl + F
৬. MS Word-এ পেজের মাপ, ওরিয়েন্টেশন এবং মার্জিন কোন ট্যাবে থাকে?
(A) Home   (B) Insert   (C) Layout / Page Layout   (D) View
সঠিক উত্তর: (C) Layout / Page Layout
৭. লেখাকে আন্ডারলাইন (Underline) করার শর্টকাট কমান্ড কোনটি?
(A) Ctrl + U   (B) Ctrl + I   (C) Ctrl + B   (D) Ctrl + Shift + U
সঠিক উত্তর: (A) Ctrl + U
৮. MS Word ফাইলে 'Save As' করার জন্য কিবোর্ডের কোন ফাংশন কী (Key) চাপতে হয়?
(A) F1   (B) F5   (C) F7   (D) F12
সঠিক উত্তর: (D) F12
৯. ডকুমেন্টের একদম উপরে ও নিচে যে লেখা সব পেজে থাকে তাকে কী বলে?
(A) Top & Bottom   (B) Header & Footer   (C) Margin   (D) Border
সঠিক উত্তর: (B) Header & Footer
১০. ডকুমেন্টটি প্রিন্ট করার আগে কেমন দেখাবে তা দেখার জন্য (Print Preview) কোনটি ব্যবহৃত হয়?
(A) Ctrl + F1   (B) Ctrl + F2   (C) Alt + F2   (D) Shift + F2
সঠিক উত্তর: (B) Ctrl + F2
