💻 Computer Basic Q&A

📢 অভিভাবকদের প্রতি বিশেষ অনুরোধ:
আপনার সন্তানকে এখানে দেওয়া প্রশ্নগুলো মুখে ধরে জিজ্ঞাসা করুন।
সে উত্তর দেওয়ার পর "উত্তর দেখুন" বাটনে ক্লিক করে সঠিকতা যাচাই করুন।
১. কম্পিউটারের মস্তিষ্ক (Brain) কাকে বলা হয়?
সঠিক উত্তর: CPU (Central Processing Unit)
২. RAM এর পূর্ণরূপ (Full Form) কী?
সঠিক উত্তর: Random Access Memory
৩. কোনটি কম্পিউটারের স্থায়ী স্মৃতি বা স্টোরেজ?
সঠিক উত্তর: ROM / Hard Disk
৪. আধুনিক কম্পিউটারের জনক কাকে বলা হয়?
সঠিক উত্তর: চার্লস ব্যাবেজ (Charles Babbage)
৫. ১ কিলোবাইট (1 KB) সমান কত বাইট?
সঠিক উত্তর: ১০২৪ বাইট (1024 Bytes)
৬. ডব্লিউ ডব্লিউ ডব্লিউ (WWW) এর পূর্ণরূপ কী?
সঠিক উত্তর: World Wide Web
৭. কম্পিউটারের প্রধান আউটপুট ডিভাইস কোনটি?
সঠিক উত্তর: মনিটর (Monitor)
৮. কপি (Copy) করার শর্টকাট কী (Shortcut Key) কী?
সঠিক উত্তর: Ctrl + C
৯. মাউস (Mouse) কী ধরনের ডিভাইস? ইনপুট নাকি আউটপুট?
সঠিক উত্তর: ইনপুট ডিভাইস (Input Device)
১০. ইমেইল (Email) এর পূর্ণরূপ কী?
সঠিক উত্তর: Electronic Mail
