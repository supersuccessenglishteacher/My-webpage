🖥️ Windows Advanced Challenge (Part 2)

Super Success Computer Education Center

অ্যাডভান্সড
১১. কম্পিউটারের প্রসেসর এবং র‍্যাম (RAM) কত—তা দেখার জন্য কোন শর্টকাট ব্যবহার করা হয়?
(A) Win + Pause/Break   (B) Win + R   (C) Ctrl + Alt + Del   (D) Alt + F4
সঠিক উত্তর: (A) Win + Pause/Break
১২. সরাসরি 'File Explorer' খোলার জন্য কিবোর্ড শর্টকাট কোনটি?
(A) Win + F   (B) Win + E   (C) Win + X   (D) Win + L
সঠিক উত্তর: (B) Win + E
১৩. কম্পিউটারের স্ক্রিন লক (Lock Screen) করার দ্রুততম শর্টকাট কী কোনটি?
(A) Win + L   (B) Win + S   (C) Alt + L   (D) Ctrl + L
সঠিক উত্তর: (A) Win + L
১৪. কমান্ড প্রম্পট (Command Prompt) খোলার জন্য রান বক্সে (Run Box) কী লিখতে হয়?
(A) Command   (B) CMD   (C) WinCmd   (D) Terminal
সঠিক উত্তর: (B) CMD
১৫. উইন্ডোজের স্ক্রিনশট নেওয়ার আধুনিক শর্টকাট (Snip & Sketch) কোনটি?
(A) Win + Shift + S   (B) Win + P   (C) Alt + PrintScreen   (D) Ctrl + Shift + S
সঠিক উত্তর: (A) Win + Shift + S
১৬. কম্পিউটারে কোনো ভাইরাস চেক করার জন্য উইন্ডোজের নিজস্ব টুলের নাম কী?
(A) Windows Guard   (B) Windows Defender / Security   (C) Safe Mode   (D) System Restore
সঠিক উত্তর: (B) Windows Defender / Security
১৭. হার্ডড্রাইভের অপ্রয়োজনীয় ফাইল মুছে ফেলার জন্য কোন টুলটি ব্যবহার করা হয়?
(A) Disk Cleanup   (B) Disk Format   (C) Defragment   (D) ScanDisk
সঠিক উত্তর: (A) Disk Cleanup
১৮. বর্তমানে কম্পিউটারে কতগুলো র‍্যাম (RAM) স্লট খালি আছে তা কোথা থেকে দেখা যায়?
(A) Control Panel   (B) Task Manager   (C) My Computer   (D) Device Manager
সঠিক উত্তর: (B) Task Manager (Performance Tab)
১৯. কম্পিউটারের হার্ডওয়্যার সংক্রান্ত সমস্যার সমাধান বা ড্রাইভ আপডেট করার জায়গা কোনটি?
(A) Device Manager   (B) File Manager   (C) Task Manager   (D) Program Manager
সঠিক উত্তর: (A) Device Manager
২০. উইন্ডোজের 'Quick Access Menu' (যা স্টার্ট বাটনে রাইট ক্লিক করলে আসে) দেখার শর্টকাট কোনটি?
(A) Win + X   (B) Win + Q   (C) Win + Z   (D) Win + I
সঠিক উত্তর: (A) Win + X
