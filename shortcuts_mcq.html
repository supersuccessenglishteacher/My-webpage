বেসিক শর্টকাট
১. কোনো লেখা বা ছবি 'কপি' (Copy) করার শর্টকাট কমান্ড কোনটি?
(A) Ctrl + V   (B) Ctrl + C   (C) Ctrl + X   (D) Ctrl + S
সঠিক উত্তর: (B) Ctrl + C
২. কপি করা লেখা বা ছবি 'পেস্ট' (Paste) করার জন্য কোনটি ব্যবহার করা হয়?
(A) Ctrl + P   (B) Ctrl + Z   (C) Ctrl + V   (D) Ctrl + A
সঠিক উত্তর: (C) Ctrl + V
৩. করা কোনো কাজ ভুল হলে তা এক ধাপ পিছিয়ে যাওয়ার জন্য (Undo) কোনটি চাপতে হয়?
(A) Ctrl + U   (B) Ctrl + Y   (C) Ctrl + Z   (D) Ctrl + R
সঠিক উত্তর: (C) Ctrl + Z
৪. কম্পিউটারে কোনো ফাইল বা ডকুমেন্ট 'সেভ' (Save) করার কমান্ড কোনটি?
(A) Ctrl + S   (B) Ctrl + O   (C) Ctrl + N   (D) Ctrl + F
সঠিক উত্তর: (A) Ctrl + S
৫. পেজের সমস্ত লেখা একবারে 'সিলেক্ট' (Select All) করার জন্য কোনটি ব্যবহৃত হয়?
(A) Ctrl + S   (B) Ctrl + A   (C) Ctrl + E   (D) Ctrl + L
সঠিক উত্তর: (B) Ctrl + A
৬. কোনো ফাইল বা লেখাকে 'কাট' (Cut) করার জন্য কোন শর্টকাট ব্যবহার করা হয়?
(A) Ctrl + C   (B) Ctrl + V   (C) Ctrl + X   (D) Ctrl + K
সঠিক উত্তর: (C) Ctrl + X
৭. টাইপ করা টেক্সটকে 'বোল্ড' (Bold) বা মোটা করার কমান্ড কোনটি?
(A) Ctrl + M   (B) Ctrl + B   (C) Ctrl + D   (D) Ctrl + T
সঠিক উত্তর: (B) Ctrl + B
৮. কোনো ডকুমেন্ট 'প্রিন্ট' (Print) করার জন্য কোনটি চাপতে হয়?
(A) Ctrl + P   (B) Ctrl + R   (C) Ctrl + I   (D) Ctrl + G
সঠিক উত্তর: (A) Ctrl + P
৯. বর্তমান চালু থাকা উইন্ডো বা প্রোগ্রাম 'বন্ধ' (Close) করার শর্টকাট কোনটি?
(A) Alt + F1   (B) Alt + F4   (C) Ctrl + Q   (D) Shift + Esc
সঠিক উত্তর: (B) Alt + F4
১০. স্টার্ট মেনু ওপেন করার জন্য কীবোর্ডের কোন বাটনটি সরাসরি ব্যবহার করা যায়?
(A) Ctrl   (B) Alt   (C) Windows Key   (D) Tab
সঠিক উত্তর: (C) Windows Key
