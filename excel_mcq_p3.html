প্রফেশনাল লেভেল
২১. শর্ত অনুযায়ী সেলের রং পরিবর্তন করার পদ্ধতিকে কী বলে?
(A) Auto Formatting   (B) Conditional Formatting   (C) Style Cell   (D) Data Validation
সঠিক উত্তর: (B) Conditional Formatting
২২. এক্সেল শিটে অনেক বড় ডাটাকে সংক্ষেপে রিপোর্ট আকারে দেখার জন্য কোনটি সেরা?
(A) Pivot Table   (B) Micro Table   (C) Filter Table   (D) Summary Sheet
সঠিক উত্তর: (A) Pivot Table
২৩. কোনো সেলের ভেতর ড্রপ-ডাউন লিস্ট (Drop-down List) তৈরি করার অপশন কোথায় থাকে?
(A) Home Tab   (B) Insert Tab   (C) Data Validation   (D) View Tab
সঠিক উত্তর: (C) Data Validation
২৪. একটি টেবিল থেকে নির্দিষ্ট ডাটা খুঁজে বের করার জন্য কোন বিখ্যাত ফর্মুলা ব্যবহার করা হয়?
(A) =LOOKUP()   (B) =VLOOKUP()   (C) =SEARCH()   (D) =FIND()
সঠিক উত্তর: (B) =VLOOKUP()
২৫. এক্সেলে কোনো শিটের নাম পরিবর্তন (Rename) করার জন্য মাউসের কোন ক্লিক করতে হয়?
(A) Left Click   (B) Right Click   (C) Double Click   (D) Both B & C
সঠিক উত্তর: (D) Both B & C (রাইট ক্লিক করে রিনেম বা সরাসরি ডাবল ক্লিক)
২৬. এক্সেলে সেলের ভেতর 'Comment' বা নোট যুক্ত করার শর্টকাট কী কোনটি?
(A) Shift + F2   (B) Ctrl + F2   (C) Alt + F2   (D) Shift + F5
সঠিক উত্তর: (A) Shift + F2
২৭. এক্সেলে শিট ইনসার্ট করার শর্টকাট কী কোনটি?
(A) Shift + F11   (B) Ctrl + N   (C) Alt + I   (D) Shift + F1
সঠিক উত্তর: (A) Shift + F11
২৮. এক্সেলে কোনো কলামের সব ডাটাকে বড় থেকে ছোট (Z-A) সাজানোকে কী বলে?
(A) Ascending Sort   (B) Descending Sort   (C) Filter   (D) Grouping
সঠিক উত্তর: (B) Descending Sort
২৯. সেলের ফরম্যাট (যেমন কালার বা বর্ডার) কপি করে অন্য সেলে দেওয়ার জন্য কোনটি ব্যবহার করা হয়?
(A) Copy Paste   (B) Format Painter   (C) Magic Brush   (D) Auto Fill
সঠিক উত্তর: (B) Format Painter
৩০. এক্সেলে কোনো একটি চার্টের নাম বা শিরোনামকে কী বলা হয়?
(A) Header   (B) Chart Title   (C) Legend   (D) Data Label
সঠিক উত্তর: (B) Chart Title
