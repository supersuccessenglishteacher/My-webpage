📝 MS Word Challenge (Part 2)

Super Success Computer Education Center

অ্যাডভান্স লেভেল
১১. MS Word-এ 'Superscript' (যেমন: X²) করার শর্টকাট কী কোনটি?
(A) Ctrl + Shift + Plus(+)   (B) Ctrl + Equals(=)   (C) Alt + S   (D) Ctrl + S
সঠিক উত্তর: (A) Ctrl + Shift + Plus(+)
১২. ডকুমেন্টে কোনো হাইপারলিঙ্ক (Hyperlink) যুক্ত করার শর্টকাট কী?
(A) Ctrl + H   (B) Ctrl + L   (C) Ctrl + K   (D) Ctrl + N
সঠিক উত্তর: (C) Ctrl + K
১৩. কোনো লেখাকে ইটালিক (Italic) বা বাঁকা করার জন্য কোনটি ব্যবহার করা হয়?
(A) Ctrl + B   (B) Ctrl + I   (C) Ctrl + U   (D) Ctrl + J
সঠিক উত্তর: (B) Ctrl + I
১৪. ডকুমেন্টের লাইনের শুরুতে যাওয়ার জন্য কিবোর্ডের কোন বোতামটি চাপতে হয়?
(A) Page Up   (B) End   (C) Home   (D) Ctrl + Home
সঠিক উত্তর: (C) Home
১৫. MS Word-এ বানান ও ব্যাকরণ (Spelling & Grammar) চেক করার ফাংশন কী কোনটি?
(A) F1   (B) F2   (C) F5   (D) F7
সঠিক উত্তর: (D) F7
১৬. একটি নতুন টেবিল ইনসার্ট করার অপশন কোন ট্যাবে পাওয়া যায়?
(A) Home   (B) Insert   (C) Layout   (D) View
সঠিক উত্তর: (B) Insert
১৭. পেজের সব লেখাকে একসাথে জাস্টিফাই (Justify) করার শর্টকাট কী?
(A) Ctrl + L   (B) Ctrl + R   (C) Ctrl + J   (D) Ctrl + E
সঠিক উত্তর: (C) Ctrl + J
১৮. একই সাথে অনেক মানুষকে চিঠি বা মেইল পাঠানোর পদ্ধতিকে কী বলে?
(A) Mail Merge   (B) Macro   (C) Hyperlink   (D) Cross-reference
সঠিক উত্তর: (A) Mail Merge
১৯. লেখা বা প্যারাগ্রাফের লাইনগুলোর মাঝখানের দূরত্বকে কী বলা হয়?
(A) Word Spacing   (B) Line Spacing   (C) Letter Spacing   (D) Paragraph Spacing
সঠিক উত্তর: (B) Line Spacing
২০. ডকুমেন্টের কোনো শব্দ রিপ্লেস (Replace) করার শর্টকাট কী কোনটি?
(A) Ctrl + R   (B) Ctrl + F   (C) Ctrl + H   (D) Ctrl + K
সঠিক উত্তর: (C) Ctrl + H
