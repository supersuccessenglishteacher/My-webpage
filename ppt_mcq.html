📽️ MS PowerPoint Q&A (Part 1)

Super Success Computer Education Center

বেসিক
১. MS PowerPoint-এর একটি পেজকে কী বলা হয়?
(A) Sheet   (B) Document   (C) Slide   (D) Frame
সঠিক উত্তর: (C) Slide
২. স্লাইড শো শুরু করার জন্য কিবোর্ডের কোন ফাংশন কী চাপতে হয়?
(A) F1   (B) F2   (C) F5   (D) F7
সঠিক উত্তর: (C) F5
৩. একটি নতুন স্লাইড ইনসার্ট (Insert) করার শর্টকাট কী কোনটি?
(A) Ctrl + N   (B) Ctrl + M   (C) Ctrl + S   (D) Ctrl + D
সঠিক উত্তর: (B) Ctrl + M
৪. স্লাইড শো চলাকালীন আগের স্লাইডে ফিরে যাওয়ার জন্য কিবোর্ডের কোনটি ব্যবহার করা হয়?
(A) Enter   (B) Space   (C) Backspace   (D) Tab
সঠিক উত্তর: (C) Backspace
৫. স্লাইডের ভেতরে কোনো লেখার ওপর নড়াচড়া বা ইফেক্ট দেওয়াকে কী বলে?
(A) Transition   (B) Animation   (C) Design   (D) Slide Show
সঠিক উত্তর: (B) Animation
৬. এক স্লাইড থেকে অন্য স্লাইডে যাওয়ার সময় যে স্পেশাল ইফেক্ট দেখা যায় তাকে কী বলে?
(A) Transition   (B) Animation   (C) Motion Path   (D) Effect Option
সঠিক উত্তর: (A) Transition
৭. স্লাইডের ব্যাকগ্রাউন্ড ডিজাইন এবং লেআউট একসাথে পরিবর্তন করার অপশন কোনটি?
(A) Animations   (B) Transitions   (C) Themes   (D) Review
সঠিক উত্তর: (C) Themes (Design Tab)
৮. বর্তমান স্লাইড (Current Slide) থেকে স্লাইড শো শুরু করার শর্টকাট কোনটি?
(A) Shift + F5   (B) Ctrl + F5   (C) Alt + F5   (D) F5
সঠিক উত্তর: (A) Shift + F5
৯. স্লাইড শো চলাকালীন মাঝপথে স্লাইড বন্ধ করার জন্য কোন বাটন ব্যবহার করা হয়?
(A) Ctrl   (B) Esc   (C) Alt   (D) Delete
সঠিক উত্তর: (B) Esc (Escape)
১০. একই স্লাইডের হুবহু নকল (Duplicate) তৈরি করার শর্টকাট কী কোনটি?
(A) Ctrl + C   (B) Ctrl + V   (C) Ctrl + D   (D) Ctrl + N
সঠিক উত্তর: (C) Ctrl + D
