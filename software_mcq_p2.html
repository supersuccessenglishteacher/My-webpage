অ্যাডভান্সড
১১. কম্পিউটারের মেমোরি পরিষ্কার রাখা এবং ড্রাইভ অপ্টিমাইজ করার সফটওয়্যারগুলোকে কী বলে?
(A) System Software   (B) Application Software   (C) Utility Software   (D) Firmware
সঠিক উত্তর: (C) Utility Software (যেমন: Disk Cleanup)
১২. কোনো সফটওয়্যারের সোর্স কোড সবার জন্য উন্মুক্ত থাকলে তাকে কী বলা হয়?
(A) Closed Source   (B) Open Source   (C) Private   (D) Shared
সঠিক উত্তর: (B) Open Source (যেমন: Android, Linux)
১৩. নিচের কোনটি একটি ইমেজ বা ছবির ফাইল এক্সটেনশন?
(A) .mp3   (B) .exe   (C) .jpg   (D) .pdf
সঠিক উত্তর: (C) .jpg (বা .png)
১৪. ট্রায়াল ভার্সন হিসেবে ফ্রিতে পাওয়া যায় এমন সফটওয়্যারকে কী বলে?
(A) Shareware   (B) Freeware   (C) Firmware   (D) Malware
সঠিক উত্তর: (A) Shareware (নির্দিষ্ট সময় পর কিনতে হয়)
১৫. উইন্ডোজে কোনো সফটওয়্যার ইন্সটল করার ফাইলের এক্সটেনশন সাধারণত কী হয়?
(A) .docx   (B) .exe   (C) .mp4   (D) .zip
সঠিক উত্তর: (B) .exe (Executable File)
১৬. নিচের কোনটি একটি স্প্রেডশিট (Spreadsheet) সফটওয়্যার?
(A) MS Word   (B) MS Excel   (C) MS PowerPoint   (D) Notepad
সঠিক উত্তর: (B) MS Excel
১৭. বড় সাইজের ফাইলকে ছোট বা সংকুচিত করার সফটওয়্যার কোনটি?
(A) Browser   (B) WinRAR/WinZip   (C) Photoshop   (D) Antivirus
সঠিক উত্তর: (B) WinRAR / WinZip (Compression Software)
১৮. লিনাক্স (Linux) এবং উবুন্টু (Ubuntu) কোন ধরনের সফটওয়্যার?
(A) Application   (B) System Software   (C) Device Driver   (D) Utility
সঠিক উত্তর: (B) System Software (Operating System)
১৯. হার্ডওয়্যার পার্টসকে (যেমন: প্রিন্টার) অপারেটিং সিস্টেমের সাথে পরিচয় করিয়ে দেয় কোনটি?
(A) Desktop   (B) Device Driver   (C) Icon   (D) Folder
সঠিক উত্তর: (B) Device Driver
২০. চিরদিনের জন্য বিনামূল্যে ব্যবহারযোগ্য সফটওয়্যারকে কী বলা হয়?
(A) Shareware   (B) Freeware   (C) Paid Software   (D) Trialware
সঠিক উত্তর: (B) Freeware (যেমন: VLC, Google Chrome)
