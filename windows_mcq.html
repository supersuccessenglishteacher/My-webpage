অপারেটিং সিস্টেম
১. কম্পিউটারের সব কাজ পরিচালনা করার মূল সফটওয়্যার কোনটি?
(A) MS Word   (B) Windows   (C) Google Chrome   (D) Photoshop
সঠিক উত্তর: (B) Windows (এটি একটি Operating System)
২. ডেক্সটপের নিচে যে লম্বা বারটি থাকে তাকে কী বলা হয়?
(A) Scroll Bar   (B) Menu Bar   (C) Taskbar   (D) Status Bar
সঠিক উত্তর: (C) Taskbar
৩. কোনো ফাইল বা ফোল্ডার রিনেম (Rename) করার শর্টকাট কী কোনটি?
(A) F1   (B) F2   (C) F5   (D) F12
সঠিক উত্তর: (B) F2
৪. কম্পিউটার থেকে কোনো ফাইল পার্মানেন্টলি ডিলিট (রিসাইকেল বিনে যাবে না) করার শর্টকাট কী?
(A) Delete   (B) Ctrl + Delete   (C) Shift + Delete   (D) Alt + Delete
সঠিক উত্তর: (C) Shift + Delete
৫. কিবোর্ডের মাধ্যমে সরাসরি ডেক্সটপে (Desktop) যাওয়ার শর্টকাট কী কোনটি?
(A) Win + D   (B) Win + M   (C) Ctrl + D   (D) Alt + D
সঠিক উত্তর: (A) Win + D
৬. কম্পিউটারের সব সেটিংস (যেমন- মাউস, কিবোর্ড, পাসওয়ার্ড) কোথা থেকে পরিবর্তন করা হয়?
(A) My Computer   (B) Control Panel   (C) Task Manager   (D) Recycle Bin
সঠিক উত্তর: (B) Control Panel
৭. ওপেন থাকা সব উইন্ডোর মধ্যে সুইচ করার (এক উইন্ডো থেকে অন্যটিতে যাওয়া) শর্টকাট কী?
(A) Alt + Tab   (B) Ctrl + Tab   (C) Shift + Tab   (D) Win + Tab
সঠিক উত্তর: (A) Alt + Tab
৮. উইন্ডোজে একটি নতুন ফোল্ডার তৈরি করার শর্টকাট কী কোনটি?
(A) Ctrl + N   (B) Ctrl + Shift + N   (C) Alt + N   (D) Win + N
সঠিক উত্তর: (B) Ctrl + Shift + N
৯. কম্পিউটার হ্যাং করলে বা কোনো প্রোগ্রাম বন্ধ করতে না পারলে কোনটি ব্যবহার করা হয়?
(A) Control Panel   (B) Task Manager   (C) Computer Properties   (D) Command Prompt
সঠিক উত্তর: (B) Task Manager (Ctrl+Shift+Esc)
১০. উইন্ডোজে রান (Run) কমান্ড ডায়ালগ বক্স খোলার শর্টকাট কী কোনটি?
(A) Win + R   (B) Win + E   (C) Ctrl + R   (D) Alt + R
সঠিক উত্তর: (A) Win + R
