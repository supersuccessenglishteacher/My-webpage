১. MS Paint-এ তৈরি করা ফাইল সাধারণত কোন ফরম্যাটে সেভ হয়?
(A) .txt   (B) .mp3   (C) .png / .jpg   (D) .exe
সঠিক উত্তর: (C) .png / .jpg
২. কোনো বন্ধ আকৃতির ভেতরে একবারে রঙ ভরার জন্য কোন টুল ব্যবহার করা হয়?
(A) Pencil   (B) Fill with color   (C) Eraser   (D) Text
সঠিক উত্তর: (B) Fill with color (বালতি আইকন)
৩. পেইন্টে নিখুঁত গোল বৃত্ত আঁকার জন্য কোন কী (Key) চেপে ধরতে হয়?
(A) Ctrl   (B) Alt   (C) Shift   (D) Space
সঠিক উত্তর: (C) Shift
৪. ভুল করে মুছে ফেলা কিছু ফিরিয়ে আনতে (Undo) কোন শর্টকাট ব্যবহৃত হয়?
(A) Ctrl + S   (B) Ctrl + Z   (C) Ctrl + V   (D) Ctrl + X
সঠিক উত্তর: (B) Ctrl + Z
৫. ইরেজার (Eraser) এর সাইজ বড় করার শর্টকাট কী কোনটি?
(A) Ctrl + Plus (+)   (B) Ctrl + Minus (-)   (C) Ctrl + E   (D) Shift + E
সঠিক উত্তর: (A) Ctrl + Plus (+)
৬. ড্রয়িং-এ কিছু লেখার জন্য কোন টুলটি ব্যবহার করা হয়?
(A) Brushes   (B) Shapes   (C) Text Tool (A)   (D) Magnifier
সঠিক উত্তর: (C) Text Tool (A আইকন)
৭. বাঁকানো রেখা (Curve Line) আঁকার জন্য কোন টুল ব্যবহার করা হয়?
(A) Line   (B) Curve   (C) Polygon   (D) Pencil
সঠিক উত্তর: (B) Curve
৮. ছবির কোনো নির্দিষ্ট অংশের রঙ কপি করে অন্য জায়গায় দেওয়ার টুল কোনটি?
(A) Color Picker   (B) Airbrush   (C) Eraser   (D) Selection
সঠিক উত্তর: (A) Color Picker
৯. পেইন্ট উইন্ডোর একদম উপরে যেখানে ফাইলের নাম থাকে তাকে কী বলে?
(A) Ribbon   (B) Title Bar   (C) Status Bar   (D) Tool Box
সঠিক উত্তর: (B) Title Bar
১০. সম্পূর্ণ ড্রয়িং একবারে সিলেক্ট করার শর্টকাট কোনটি?
(A) Ctrl + S   (B) Ctrl + C   (C) Ctrl + A   (D) Ctrl + P
সঠিক উত্তর: (C) Ctrl + A
