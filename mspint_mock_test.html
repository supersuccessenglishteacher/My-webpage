গার্ডিয়ানদের জন্য: প্রশ্ন ধরুন এবং উত্তর মিলিয়ে নিন

১. পেইন্ট প্রোগ্রামে 'Eraser' টুল দিয়ে মোছার সময় কোন কালারটি ব্যাকগ্রাউন্ডে দেখা যায়?
(A) Color 1   (B) Color 2   (C) Color 3   (D) No Color
সঠিক উত্তর: (B) Color 2
২. কিবোর্ডের সাহায্যে কোনো ড্রয়িং ছোট বা বড় (Zoom In/Out) করার শর্টকাট কী?
(A) Ctrl + S   (B) Ctrl + P   (C) Ctrl + Page Up/Down   (D) Ctrl + Z
সঠিক উত্তর: (C) Ctrl + Page Up/Down
৩. আঁকা শেষ হওয়ার পর ড্রয়িং পেজটি পরিষ্কার (Delete All) করার জন্য কোনটি শর্টকাট?
(A) Ctrl+A তারপর Delete   (B) Ctrl+X   (C) Ctrl+Z   (D) Alt+F4
সঠিক উত্তর: (A) Ctrl+A তারপর Delete
৪. MS Paint-এ কত ধরনের ব্রাশ (Brushes) পাওয়া যায়?
(A) ৫টি   (B) ৭টি   (C) ৯টি   (D) ১২টি
সঠিক উত্তর: (C) ৯টি
৫. কিবোর্ডের কোন বোতাম টিপলে ইরেজার বা পেন্সিলের সাইজ ছোট হয়?
(A) Ctrl + (+)   (B) Ctrl + (-)   (C) Shift + (+)   (D) Alt + (-)
সঠিক উত্তর: (B) Ctrl + Minus (-)
৬. একটি চতুর্ভুজ বা আয়তক্ষেত্র (Rectangle) আঁকার টুল কোনটি?
(A) Oval   (B) Triangle   (C) Rectangle   (D) Diamond
সঠিক উত্তর: (C) Rectangle
৭. ড্রয়িং-এ করা শেষ কাজটি বাতিল করার শর্টকাট হলো Ctrl+Z, কিন্তু বাতিল করা কাজ ফিরে পাওয়ার (Redo) শর্টকাট কী?
(A) Ctrl + R   (B) Ctrl + Y   (C) Ctrl + X   (D) Ctrl + N
সঠিক উত্তর: (B) Ctrl + Y
৮. ছবির কোনো অংশকে উল্টে দেওয়ার জন্য (যেমন বাম দিক ডান দিকে করা) কোন অপশনটি ব্যবহৃত হয়?
(A) Rotate   (B) Flip   (C) Resize   (D) Skew
সঠিক উত্তর: (B) Flip (Horizontal/Vertical)
৯. MS Paint উইন্ডোর নিচের অংশে যেখানে পেজের মাপ বা রেজোলিউশন দেখায় তাকে কী বলে?
(A) Title Bar   (B) Ribbon   (C) Menu Bar   (D) Status Bar
সঠিক উত্তর: (D) Status Bar
১০. ড্রয়িং করা ছবিটিকে কম্পিউটারের ডেস্কটপ ব্যাকগ্রাউন্ড বা ওয়ালপেপার হিসেবে সেট করা যায় কি?
(A) হ্যাঁ   (B) না   (C) শুধু রঙিন ছবি হলে   (D) জানি না
সঠিক উত্তর: (A) হ্যাঁ (Set as desktop background)
