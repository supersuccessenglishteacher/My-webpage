মেমোরি ইউনিট
১১. কম্পিউটারের তথ্য মাপার সবচেয়ে ছোট একক কোনটি?
(A) Byte   (B) Bit   (C) KB   (D) MB
সঠিক উত্তর: (B) Bit (Binary Digit - 0 অথবা 1)
১২. কত বিট (Bit) মিলে ১ বাইট (Byte) তৈরি হয়?
(A) 4 bits   (B) 8 bits   (C) 16 bits   (D) 1024 bits
সঠিক উত্তর: (B) 8 bits
১৩. ১ গিগাবাইট (1 GB) সমান কত মেগাবাইট (MB)?
(A) 100 MB   (B) 1000 MB   (C) 1024 MB   (D) 512 MB
সঠিক উত্তর: (C) 1024 MB
১৪. নিচের কোনটি একটি প্রসেসিং ডিভাইস (Processing Device)?
(A) Monitor   (B) CPU   (C) Mouse   (D) Hard Disk
সঠিক উত্তর: (B) CPU
১৫. পেন ড্রাইভকে আর কোন নামে ডাকা হয়?
(A) Flash Drive   (B) Blue-ray   (C) Floppy Disk   (D) RAM
সঠিক উত্তর: (A) Flash Drive
১৬. নিচের কোনটি একই সাথে ইনপুট ও আউটপুট ডিভাইস হিসেবে কাজ করতে পারে?
(A) Keyboard   (B) Touch Screen Monitor   (C) Printer   (D) Speaker
সঠিক উত্তর: (B) Touch Screen Monitor
১৭. হার্ড ডিস্কের চেয়ে অনেক বেশি দ্রুত গতির স্টোরেজ ডিভাইসের নাম কী?
(A) CD-ROM   (B) SSD   (C) DVD   (D) Floppy
সঠিক উত্তর: (B) SSD (Solid State Drive)
১৮. 'VGA' পোর্ট কম্পিউটারের কোন হার্ডওয়্যারের সাথে যুক্ত থাকে?
(A) Keyboard   (B) Mouse   (C) Monitor   (D) Speaker
সঠিক উত্তর: (C) Monitor
১৯. প্রিন্টারের ছাপার মান বা রেজোলিউশন মাপার একক কোনটি?
(A) PPM   (B) DPI   (C) LPT   (D) USB
সঠিক উত্তর: (B) DPI (Dots Per Inch)
২০. কম্পিউটারের ডেটা প্রসেসিং করার সময় বর্তমান কাজগুলো সাময়িকভাবে কোথায় জমা থাকে?
(A) Hard Disk   (B) RAM   (C) ROM   (D) Pen Drive
সঠিক উত্তর: (B) RAM
