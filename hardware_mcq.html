বেসিক
১. কম্পিউটারের কোন অংশটিকে এর 'মস্তিষ্ক' (Brain) বলা হয়?
(A) Monitor   (B) CPU   (C) Keyboard   (D) Mouse
সঠিক উত্তর: (B) CPU (Central Processing Unit)
২. নিচের কোনটি কম্পিউটারের একটি 'ইনপুট' (Input) ডিভাইস?
(A) Printer   (B) Speaker   (C) Scanner   (D) Monitor
সঠিক উত্তর: (C) Scanner
৩. কম্পিউটারের অস্থায়ী স্মৃতি বা 'ভolatেইল মেমোরি' (Volatile Memory) কোনটি?
(A) Hard Disk   (B) RAM   (C) ROM   (D) Pendrive
সঠিক উত্তর: (B) RAM (Random Access Memory)
৪. কম্পিউটারের প্রধান সার্কিট বোর্ড, যেখানে সব পার্টস যুক্ত থাকে, তাকে কী বলে?
(A) Power Supply   (B) Graphics Card   (C) Motherboard   (D) Sound Card
সঠিক উত্তর: (C) Motherboard
৫. কম্পিউটারে স্থায়ীভাবে ডেটা জমা রাখার জন্য কোনটি ব্যবহৃত হয়?
(A) RAM   (B) Hard Disk / SSD   (C) Cache Memory   (D) Register
সঠিক উত্তর: (B) Hard Disk / SSD
৬. CPU-এর ভেতর গাণিতিক ও যুক্তিমূলক কাজগুলো কে সম্পন্ন করে?
(A) Control Unit   (B) ALU   (C) Memory Unit   (D) Register
সঠিক উত্তর: (B) ALU (Arithmetic Logic Unit)
৭. পেন ড্রাইভ বা মাউস কম্পিউটারে লাগানোর জায়গাকে কী বলা হয়?
(A) Port   (B) Slot   (C) Socket   (D) Bus
সঠিক উত্তর: (A) Port (যেমন USB Port)
৮. বিদ্যুৎ চলে যাওয়ার পরও কম্পিউটারকে কিছু সময় চালু রাখে কোনটি?
(A) CPU   (B) UPS   (C) SMPS   (D) RAM
সঠিক উত্তর: (B) UPS (Uninterruptible Power Supply)
৯. নিচের কোনটি একটি 'আউটপুট' (Output) ডিভাইস?
(A) Microphone   (B) Light Pen   (C) Speaker   (D) Keyboard
সঠিক উত্তর: (C) Speaker
১০. হার্ডওয়্যার এবং ইউজারের মধ্যে সরাসরি যোগাযোগ রক্ষা করে কোনটি?
(A) MS Word   (B) Operating System   (C) Photoshop   (D) Google Chrome
সঠিক উত্তর: (B) Operating System (যেমন Windows)
