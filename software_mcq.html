বেসিক
১. কম্পিউটারের যে অংশগুলো ছোঁয়া যায় না কিন্তু কাজের নির্দেশ দেয়, তাদের কী বলে?
(A) Hardware   (B) Software   (C) CPU   (D) RAM
সঠিক উত্তর: (B) Software
২. নিচের কোনটি একটি 'অপারেটিং সিস্টেম' (System Software)?
(A) MS Paint   (B) Windows 10   (C) Google Chrome   (D) MS Word
সঠিক উত্তর: (B) Windows 10
৩. কোনো নির্দিষ্ট কাজের জন্য (যেমন- ছবি আঁকা বা গান শোনা) যে সফটওয়্যার ব্যবহৃত হয় তাকে কী বলে?
(A) System Software   (B) Application Software   (C) Hardware   (D) Utility
সঠিক উত্তর: (B) Application Software
৪. কম্পিউটারের ক্ষতিকারক ভাইরাস দূর করার জন্য কোন সফটওয়্যার প্রয়োজন?
(A) Web Browser   (B) Antivirus   (C) Media Player   (D) Photoshop
সঠিক উত্তর: (B) Antivirus
৫. ইন্টারনেটে ওয়েবসাইট দেখার জন্য কোন সফটওয়্যারটি ব্যবহৃত হয়?
(A) MS PowerPoint   (B) Web Browser   (C) Excel   (D) Calculator
সঠিক উত্তর: (B) Web Browser (যেমন: Chrome, Firefox)
৬. নিচের কোনটি একটি 'এপ্লিকেশন সফটওয়্যার' নয়?
(A) MS Word   (B) Linux   (C) Photoshop   (D) VLC Player
সঠিক উত্তর: (B) Linux (এটি একটি অপারেটিং সিস্টেম)
৭. ফোনের জন্য সবচেয়ে জনপ্রিয় অপারেটিং সিস্টেম কোনটি?
(A) Windows   (B) Android   (C) MS Office   (D) MacOS
সঠিক উত্তর: (B) Android
৮. গান শোনার বা ভিডিও দেখার জন্য নিচের কোনটি ব্যবহৃত হয়?
(A) Database   (B) Media Player   (C) Browser   (D) Spreadsheet
সঠিক উত্তর: (B) Media Player
৯. কম্পিউটারের সব হার্ডওয়্যারকে কাজ করার জন্য নিয়ন্ত্রণ করে কে?
(A) Game   (B) Operating System   (C) Paint   (D) Mouse
সঠিক উত্তর: (B) Operating System
১০. গুগল ক্রোম (Google Chrome) কী ধরনের সফটওয়্যার?
(A) System Software   (B) Browser   (C) Operating System   (D) Drawing Software
সঠিক উত্তর: (B) Browser
